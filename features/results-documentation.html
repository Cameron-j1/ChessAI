Results & Documentation

Technical Documentation

System Architecture

The ChessAI system consists of several key components:

  • Chess Engine Core: Implements the game logic and move generation
  • AI Models: SVM-based move evaluator and DQN for strategic decision making
  • Robotics Interface: Integration with UR3e robotic arm and custom hardware
  • Web Interface: User interaction and game visualization

Implementation Details

Chess Engine

  • Move generation using bitboard representation
  • Alpha-Beta pruning with iterative deepening
  • Adaptive search depth based on position complexity
  • Check extension and quiescence search

AI Components

  • SVM model trained on 16,000 high-quality games
  • Feature engineering for position evaluation
  • DQN implementation with experience replay
  • Reward shaping for strategic learning

Robotics Integration

UR3e Robotic Arm

Controlled via ROS2 for precise piece movements

Custom End Effector

Specialized design for reliable piece manipulation

Computer Vision

Advanced board state detection system

Chess Clock System

Custom GUI and housing for automated timing

API Documentation

Key interfaces and endpoints:

  • Lichess API integration for online play
  • Robotics Studio 2 ROS2 Node for arm control
  • REST API for game state management

Training and Optimization

Data Constraints

Due to limited computational resources, we were constrained to training on 3.9 million chess positions. While this was sufficient for our initial smaller network, it presented challenges when we expanded the network architecture to increase the bot's strength:

Overfitting Challenges

As we expanded the network to increase the bot's playing strength, we encountered significant overfitting issues due to the limited training data. This manifested in:

  • Poor generalization to new positions
  • Memorization of specific game patterns
  • Inconsistent performance against different playing styles

Solutions Implemented

1. Dropout Regularization

Implemented dropout during training to prevent overfitting:

  • Randomly sets a fraction of neurons to zero during training
  • Forces the network to not rely too heavily on specific neurons
  • Prevents memorization by prioritizing generalization
  • Creates a more robust network that can handle varied positions
2. Weight Decay

Added weight decay for parameter regularization:

  • Penalizes large weights to constrain model complexity
  • Forces the model to prefer smaller weights
  • Prevents sharp, dramatic decision changes based on specific inputs
  • Encourages smoother, more generalized decision boundaries

Impact on Performance

These optimizations led to significant improvements:

  • Better generalization to new positions
  • More consistent performance across different playing styles
  • Reduced variance in move quality
  • Improved overall playing strength

Key Achievements

  • Successfully implemented an attention-based neural network architecture for move prediction
  • Trained the model on over 1 million chess positions from master-level games
  • Achieved strong performance through spatial move encoding and position evaluation
  • Integrated with Lichess API for online play against human opponents
  • Created a functional Chess Robot that brings the AI into the physical world
