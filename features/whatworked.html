SVM-Based Move Evaluation

Our chess engine successfully implemented a Support Vector Machine (SVM) model trained on a high-quality dataset of 16,000 games played by strong players (2000+ ELO rating). This extensive training on master-level games allowed the model to learn sophisticated strategic patterns and tactical motifs.

The SVM model effectively evaluates positions using a sophisticated feature set including:

  • Material balance and piece values
  • Piece-square table evaluations
  • Center control and mobility
  • King safety metrics
  • Pawn structure analysis

Evolution to Spatial Move Prediction

We successfully evolved from categorical move prediction to a more intuitive spatial approach:

  • From Categorical to Spatial: Replaced the previous system of assigning numbers to moves with a more natural 8x8 board representation
  • Dual Output Heads: Implemented separate prediction heads for source and destination squares, making the model's output more analogous to the input
  • Improved Learning: The spatial representation allows the model to better understand and learn board relationships and piece movements

Attention-Based Neural Network

We successfully implemented a sophisticated attention-based neural network architecture inspired by Large Language Models:

  • Multi-Head Board Attention: Implemented an 8-head attention mechanism that captures complex relationships between any squares on the board
  • Long-Range Understanding: Attention mechanism enables the model to understand complex chess concepts like forks, pins, and discovered attacks by connecting distant board positions
  • Residual Learning: Deep network with 8 alternating residual and attention blocks for robust feature extraction
  • Overfitting Prevention: Implemented dropout (0.2) and weight decay (2e-4) to prevent the model from memorizing training data and ensure it learns core chess concepts
class MultiHeadBoardAttention(nn.Module): def __init__(self, channels, num_heads=8, head_dim=32, dropout=0.1): super(MultiHeadBoardAttention, self).__init__() self.num_heads = num_heads self.head_dim = head_dim self.scale = head_dim ** -0.5 # Projections for Q, K, V self.q_proj = nn.Conv2d(channels, num_heads * head_dim, 1) self.k_proj = nn.Conv2d(channels, num_heads * head_dim, 1) self.v_proj = nn.Conv2d(channels, num_heads * head_dim, 1) self.out_proj = nn.Conv2d(num_heads * head_dim, channels, 1) self.dropout = nn.Dropout(dropout) def forward(self, x): batch_size, _, H, W = x.shape # Project and reshape to (batch, heads, H*W, head_dim) q = self.q_proj(x).view(batch_size, self.num_heads, self.head_dim, H*W).transpose(-2, -1) k = self.k_proj(x).view(batch_size, self.num_heads, self.head_dim, H*W).transpose(-2, -1) v = self.v_proj(x).view(batch_size, self.num_heads, self.head_dim, H*W).transpose(-2, -1) # Compute attention scores attn = torch.matmul(q, k.transpose(-2, -1)) * self.scale attn = F.softmax(attn, dim=-1) attn = self.dropout(attn) # Apply attention to values out = torch.matmul(attn, v) # Reshape back to board format out = out.transpose(-2, -1).contiguous().view(batch_size, -1, H, W) return self.out_proj(out)

Efficient Move Generation

The engine implements a streamlined move selection process:

  • Fast Response Time: Moves are generated in under 0.2 seconds without position caching
  • Checkmate Priority: First searches for forced checkmate sequences before considering neural network moves
  • Smart Filtering: Neural network moves (95% of all moves) are filtered to prevent obvious blunders and checkmate threats
  • Direct Move Generation: The neural network directly outputs move probabilities without requiring complex evaluation functions
def get_model_move(self, board: chess.Board, move_num: int, is_white: bool, output_LAN: bool = False) -> Optional[str]: # First check for checkmate sequences checkmate_move = self.checkmate_search(board) if checkmate_move: return checkmate_move # Get model's move probabilities X_tensor = self.prepare_input(board) with torch.no_grad(): probabilities = self.model(X_tensor.to(self.device)) # Get legal moves and their probabilities legal_moves = list(board.legal_moves) move_probs = self._get_spatial_candidate_moves(probabilities, legal_moves) # Try moves in order of probability for move, prob in move_probs: if self._validate_and_check_move(board, move, 0, move_num, is_white, set()): return move.uci()
