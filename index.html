Project Overview

ChessAI is an advanced chess engine that combines machine learning with traditional chess algorithms. The project features a sophisticated SVM-based move evaluator trained on 16,000 high-quality games, and implements advanced techniques like Alpha-Beta pruning and adaptive search depth.

Robotics Integration

Our project extends beyond software, featuring a fully automated chess robot built on a UR3e robotic arm. The system includes:

  • Custom-designed chessboard with integrated sensors
  • Specialized end effector for precise piece manipulation
  • Automated chess clock system
  • Full integration with Robotics Studio 2 for motion planning and control
